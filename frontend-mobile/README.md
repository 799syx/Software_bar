# 灵山胜境移动导览端

`frontend-mobile` 是独立的游客手机/景区触屏终端前端，不包含管理后台，不依赖 Vue 构建。

## 访问方式

启动后端：

```bash
python backend/app.py
```

手机或终端访问：

```text
http://后端IP:8000/mobile/
```

本机演示：

```text
http://127.0.0.1:8000/mobile/
```

如果移动端静态文件部署在其他域名，可通过查询参数指定 API：

```text
https://your-mobile-site/mobile/?api=http://后端IP:8000
```

## 功能范围

- 景点列表与单景点讲解。
- 文字问答与浏览器语音输入。
- 浏览器语音播报。
- 图片上传讲解。
- 个性化路线推荐。
- GPS 附近景点推荐。
- PWA 缓存移动端外壳和核心图片。

## 离线行为

移动端离线时会优先显示浏览器缓存的外壳、景点缓存和本地兜底资料。`/api` 请求不会被 Service Worker 缓存，避免游客看到过期问答结果。

真正无公网使用时，需要后端和 SQLite 数据库部署在景区局域网内；如果还要离线大模型能力，需要在局域网服务器或边缘工作站部署本地模型服务，并把 `.env` 中的模型地址改到该服务。
