# 竞品调研与优化记录

## 调研对象

- 深层互联手机智能导览系统：https://www.depthlink.com/product/
- 道可云智慧景区导览系统：https://www.daokeyun.com/index.php/3792
- 岱昊科技智慧旅游方案：https://www.daihao.net/smart-tourism
- 互动力 iPOW 文旅数字化宾客系统：https://www.ipow.cn/
- Personal-Guide AI Tour Guide：https://www.personal-guide.ai/
- Driftscape Tourism Platform：https://www.driftscape.com/

## 关键启发

1. 游客端需要把入口做短：同类产品普遍强调扫码、定位、语音、AR/图片识别、路线推荐等入口，减少游客寻找功能的成本。
2. 数字人不应只是静态形象：数字人导游产品通常会强调语音问答、动作驱动、形象 IP 和景区文化适配，因此本项目需要强化口型、眼神、表情和运行状态反馈。
3. 个性化导览要围绕兴趣、节奏和位置展开：Personal-Guide、Driftscape 等产品突出按兴趣生成讲解内容、按路线/位置组织音频导览，本项目应将兴趣路线、附近景点和拍照讲解放在游客端主路径中。
4. 管理端要能快速维护知识：成熟智慧景区方案强调一套后台、内容即时生效、导览数据可看，因此本项目需要保留景点、知识库、数字人配置、问答记录和运营看板的一体化后台。
5. 数据看板要面向运营动作：同类智慧旅游方案常见游客画像、行为分析、热点区域、偏好洞察和服务建议，本项目的数据大屏应持续输出热门问答、热门景点、情感分布和服务建议。

## 已落地优化

- 游客端首屏新增导览入口条：自由问答、语音提问、拍照讲解、定位推荐、路线规划可以直接触发。
- 后台知识库新增文档导入：支持导入文本、Markdown、CSV、JSON 资料，自动推断知识分类，保存后进入 RAG 知识库。
- 数字人舞台增强：新增状态标签、运行指示灯、音量条、眼神跟随、表情标签和停止播报控制。
- 数字人驱动增强：`DigitalHumanPanel.vue` 统一呈现口型、音量条、状态标签和待机/聆听/生成/讲解状态。
- 管理端数字人形象模块新增状态预览，便于现场演示“待机、聆听、思考、讲解”四类状态。

## 后续可扩展方向

- 增加二维码/景点编号触发讲解，与现场标识牌联动。
- 增加中英文切换和多语言 TTS，覆盖外籍游客场景。
- 增加地图轨迹和点位自动播报，把“附近景点推荐”升级成路线中的位置触发讲解。
- 引入真实景区客流数据或模拟客流热力图，增强数据大屏的管理价值。
