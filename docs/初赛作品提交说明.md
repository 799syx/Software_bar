# 初赛作品提交说明

本项目按 A5「景区导览服务 AI 数字人」题目要求组织提交材料。默认提交源码、文档、公开资料包和必要静态资源，不提交本机密钥、依赖目录、运行数据库或临时截图。

## 1. 提交物对应关系

| 题目要求 | 本项目对应文件 |
| --- | --- |
| 产品源代码或可执行文件 | `backend/`、`frontend-vue/`、`frontend-mobile/`、`tests/`、`scripts/`、`requirements.txt`、`start_demo.bat` |
| 产品部署和使用手册 | `docs/部署与使用手册.md` |
| 产品总体设计文档 | `docs/总体设计文档.md`、`docs/技术实现文档.md` |
| 产品方案介绍 PPT | `docs/产品方案介绍PPT.pptx` |
| 产品演示视频 | `docs/产品演示视频.mp4`、`docs/演示与答辩脚本.md` |
| 评测与标准测试集 | `docs/标准测试集.md`、`docs/评测标准与技术选型说明.md` |
| 交付打包脚本 | `scripts/package_delivery.ps1` |

## 2. 一键打包

在项目根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/package_delivery.ps1
```

脚本会在 `delivery/` 下生成 `scenic-guide-delivery-时间戳.zip`，并默认排除 `.env`、`node_modules`、`frontend-vue/dist`、`.tmp`、运行数据库、缓存、日志和压缩包。

## 3. 演示视频说明

项目已提供 `docs/产品演示视频.mp4`，时长约 46 秒，格式为 `.mp4`，用于快速展示作品定位、游客端、管理端、RAG 问答和交付情况。若需正式答辩版本，可按 `docs/演示与答辩脚本.md` 录制 7 分钟以内的带讲解视频，建议依次展示：

1. 题目背景、系统定位和数字人形象。
2. 游客端文字/语音问答、口型和表情联动。
3. 景区知识库问答、来源引用、置信度和满意度反馈。
4. 图片识别讲解、GPS/点位码定位和个性化路线推荐。
5. 管理后台知识库、数字人配置、低置信问题沉淀和数据看板。
6. 稳定性兜底：本地知识快答、浏览器语音、地图和定位降级方案。

正式录制视频建议保持 `.mp4` 格式，并与打包 zip、PPT 一起提交。
