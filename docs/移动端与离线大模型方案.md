# 移动端与离线大模型方案

## 1. 前端拆分

当前项目保留两个前端：

| 目录 | 定位 | 访问 |
| --- | --- | --- |
| `frontend-vue` | 完整演示端，包含首页、智能导览和管理后台 | `http://127.0.0.1:5173` 或后端根路径 |
| `frontend-mobile` | 游客手机和景区触屏终端专用端 | `http://127.0.0.1:8000/mobile/` |

移动端是静态 PWA，不需要单独构建。后端 `backend/app.py` 会直接把它挂载到 `/mobile/`。

## 2. 景区终端部署

推荐拓扑：

1. 景区局域网服务器运行后端和 SQLite。
2. 游客手机连接景区 Wi-Fi 后访问 `http://服务器IP:8000/mobile/`。
3. 景区触屏终端使用浏览器全屏模式打开同一地址。
4. 管理人员仍使用 `frontend-vue` 或后端根路径进入管理后台。

若没有公网，但局域网可用，景点资料、路线、问答记录、反馈和规则兜底都可以继续工作。

## 3. 无公网时大模型怎么办

分三档：

| 档位 | 方案 | 成本 | 适用 |
| --- | --- | --- | --- |
| 基础离线 | SQLite 知识库 + 关键词检索 + 规则兜底 | 低 | 必须保证可用的比赛演示和景区应急 |
| 局域网小模型 | 部署 OpenAI 兼容本地模型服务，如 vLLM/Ollama/LM Studio | 中 | 文字问答离线可用 |
| 局域网多模态模型 | 部署 Qwen-VL/Qwen3-VL 开源规格或其他视觉语言模型 | 高 | 图片讲解也要离线可用 |

项目现有 `.env` 已支持切换：

```text
SCENIC_LLM_PROVIDER=custom
SCENIC_LLM_MODEL=your-local-model
SCENIC_LLM_BASE_URL=http://局域网模型服务器:端口/v1
SCENIC_LLM_API_KEY=
SCENIC_VISION_PROVIDER=custom
SCENIC_VISION_MODEL=your-local-vl-model
SCENIC_VISION_BASE_URL=http://局域网模型服务器:端口/v1
SCENIC_VISION_API_KEY=
```

## 4. 需要训练吗

当前阶段不建议训练大模型。更稳妥的顺序是：

1. 先整理官方资料包、景点知识库和标准测试集。
2. 用 RAG 检索把资料喂给通义千问或本地模型。
3. 低置信问题从管理后台转成待补充知识。
4. 只有当回答风格、术语或本地小模型效果仍明显不足时，再考虑微调。

训练或微调不是解决“景区资料准确性”的第一选择。景区信息会频繁变化，票务、演出、开放时间更适合放知识库和后台维护，而不是固化进模型参数。

## 5. 百炼/通义千问模型选择

在线演示推荐：

- 质量优先：`qwen3-vl-plus`
- 延迟优先：`qwen3-vl-flash`

离线部署时优先考虑开源视觉语言模型的小规格版本，先验证显存、延迟和中文讲解质量，再决定是否升级规格或做微调。
