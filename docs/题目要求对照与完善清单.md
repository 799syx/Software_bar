# A5 题目要求对照与完善清单

## 1. 功能完整性

已覆盖：

- 游客多模态交互：文字问答、语音转文字、语音播报、图片讲解、定位推荐，以及数字人表情/口型状态联动。
- 智能问答与导览：文字问答默认调用大模型，官方资料包作为 RAG 上下文，模型不可用时使用规则兜底。
- 个性化路线推荐：支持按时长和偏好生成路线，偏好包含佛教文化、历史文化、亲子游、拍照打卡、自然风光、演艺体验、餐饮购物。
- 管理后台：景点、知识文档、数字人配置、问答记录、满意度反馈、运营概览、低置信问答沉淀和资料包重新导入。
- 官方资料接入：启动时自动读取 `示范景区公开资料包` 中的灵山胜境 docx/xlsx，生成景点与知识文档。
- Vue 3 前端：游客端展示智能导览、语音、图片讲解和路线推荐；管理后台展示景点、知识库、数字人配置、问答记录、满意度反馈和运营看板。

继续可增强：

- 路线规划可进一步加入拥堵、天气、老人/儿童体力参数。

## 2. 技术与创新性

已覆盖：

- 大模型：OpenAI 兼容接口，默认 DashScope `qwen3-vl-plus`。
- 多模态：图片讲解使用视觉语言模型，文字问答使用同一模型能力。
- RAG：先检索官方资料，再将相关景点与资料摘要传入模型，降低幻觉。
- 语音：浏览器 Web Speech API 做语音转文字，豆包 TTS 或浏览器语音合成做播报兜底；播报进度会驱动数字人口型变化。
- 数据持久化：SQLite 保存景点、知识、问答、路线、反馈和数字人配置。
- 前端可视化：Vue 前端接入 ECharts 展示满意度趋势、热门景点和游客兴趣偏好；首页使用 Wikimedia Commons 授权实景照片提升真实景区辨识度。

继续可增强：

- 弱网场景可接入本地 Whisper/faster-whisper，提高语音识别稳定性。
- 数字人形象当前使用原创 2D 小僧童 PNG 与前端状态驱动层，已支持待命、聆听、思考、讲解、异常等表情/口型变化；后续可继续接入 2D SDK 或 Live2D 模型增强精细口型。
- 正式版可进一步将浏览器语音识别改造成 WebSocket 流式 ASR，并把当前原创小僧童 PNG 状态驱动升级为 Live2D/Three.js 模型。

## 3. 行业实用性

已覆盖：

- 针对信息分散：游客端集中提供问答、路线、图片、语音和定位入口。
- 针对个性化不足：路线推荐可按游客偏好生成。
- 针对导览信息滞后：后台知识文档和景点资料更新后即时影响游客端。
- 针对服务质量监测不足：管理台展示问答量、路线量、满意度、热门问题和服务建议。

继续可增强：

- 接入真实客流或排队数据后，可输出更贴近现场的错峰建议。
