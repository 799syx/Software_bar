# 景区导览服务 AI 数字人系统开发路线

## 1. 当前项目方向

项目选择 A5「景区导览服务 AI 数字人」，最终目标是完成一个可演示的 AI 文旅导览平台，包含游客端、管理端、AI 问答、景点导览、路线推荐、知识库管理和数据看板。

## 2. 开发原则

1. 先完成可运行版本，再逐步增强 AI 能力和展示效果。
2. 优先保证比赛演示链路完整，不在早期追求复杂功能。
3. 使用“本地业务系统 + 云端多模态 API”的方案，降低本机硬件和模型部署风险。
4. 每个阶段都保留可展示成果，方便录制视频和制作 PPT。

## 3. 阶段一：项目骨架搭建

### 目标

完成前后端基础项目结构，保证系统能够启动。

### 任务

1. 创建 `backend` 后端目录。
2. 创建 `frontend-vue` 前端目录。
3. 搭建 Python 标准库后端基础服务。
4. 搭建 Vue 3 + TypeScript 前端基础页面。
5. 编写项目 `README.md`。

### 产出

1. 后端接口服务可启动。
2. 前端页面可访问。
3. 项目目录结构清晰。

## 4. 阶段二：基础数据与景点功能

### 目标

完成景点数据模型、示例数据和游客端景点浏览能力。

### 任务

1. 设计数据库模型。
2. 初始化 SQLite 数据库。
3. 准备示例景区和景点数据。
4. 实现景点列表接口。
5. 实现景点详情接口。
6. 实现游客端首页和景点详情页。

### 产出

1. 游客可以浏览景区景点。
2. 系统具备基本图文展示能力。

## 5. 阶段三：AI 导览问答

### 目标

完成游客端 AI 数字人问答页面，并实现“本地知识库 + 多模态大模型 API + 规则兜底”的问答链路。

### 任务

1. 实现聊天接口。
2. 实现问答记录存储。
3. 实现游客端 AI 导览页。
4. 增加快捷问题。
5. 增加浏览器语音播报。
6. 准备常见问题演示数据。

### 产出

1. 游客可以和 AI 数字人对话。
2. 问答记录可以保存。
3. 答辩时可以完整演示导览问答。

## 6. 阶段四：路线推荐功能

### 目标

根据游客时长和偏好生成个性化路线。

### 任务

1. 设计路线推荐输入参数。
2. 编写基于规则的推荐算法。
3. 实现路线推荐接口。
4. 实现路线推荐页面。
5. 保存路线推荐记录。
6. 增加推荐理由展示。

### 产出

1. 游客可以选择偏好生成路线。
2. 系统可以展示路线景点顺序和推荐理由。

## 7. 阶段五：管理端后台

### 目标

完成景区管理员使用的后台管理页面。

### 任务

1. 实现管理员登录。
2. 实现景点管理页面。
3. 实现知识库管理页面。
4. 实现问答记录页面。
5. 实现数据看板页面。
6. 使用前端原生组件展示统计图表，后续可升级 ECharts。

### 产出

1. 管理员可以维护景点和知识库。
2. 管理员可以查看游客问答和运营统计。

## 8. 阶段六：RAG 知识库增强

### 目标

接入知识库检索，让 AI 回答基于景区资料生成。

### 任务

1. 实现知识文档分段。
2. 实现向量库索引构建。
3. 实现相似知识检索。
4. 设计 AI 问答提示词。
5. 接入 DashScope `qwen3-vl-plus` 多模态大模型接口。
6. 增加无模型时的兜底回答。

### 产出

1. AI 回答能够引用景区知识。
2. 回答准确性和项目技术含量提升。

## 9. 阶段七：演示与提交材料

### 目标

完成比赛提交需要的文档、PPT 和演示视频准备。

### 任务

1. 完善 `README.md` 和部署说明。
2. 编写系统使用说明。
3. 准备项目演示脚本。
4. 制作答辩 PPT 大纲。
5. 准备演示视频流程。
6. 检查评分项对应功能。

### 产出

1. 完整项目源码。
2. 完整说明文档。
3. 演示 PPT 和视频脚本。

## 10. 当前收尾顺序

建议后续按以下顺序推进：

1. 申请并配置 DashScope API Key。
2. 用 `qwen3-vl-plus` 或 `qwen3-vl-flash` 完成文字问答和图片识别联调。
3. 按 `docs/标准测试集.md` 自测 30-50 条事实问题。
4. 根据错误问题补充知识库。
5. 录制语音问答、图片识别、GPS 定位和管理端知识库编辑演示。
6. 准备 PPT 和 7 分钟演示视频。
7. 视时间增加管理端鉴权、TTS 音色优化和口型同步增强。

## 11. 当前实现进度（2026-06-06）

当前工程已经从最小可运行版本推进到 A5 可演示版本，已完成：

1. 标准库 HTTP 后端、SQLite 数据库和静态前端一体化启动。
2. 游客端 AI 数字人问答、快捷问题、语音输入、语音播报和口型动画。
3. 景区知识库表、知识管理接口和轻量检索增强问答。
4. 景点管理、知识库管理、数字人形象配置和问答记录查看。
5. 个性化路线推荐与路线记录保存。
6. 游客满意度反馈、情感分析、热门问题、热门景点、偏好分布和服务建议。
7. README、部署与使用手册、演示与答辩脚本等提交材料。

后续优先级建议调整为：

1. 填写 `DASHSCOPE_API_KEY`，完成多模态 API 真机联调。
2. 将关键词检索升级为向量检索，增加知识片段召回准确率。
3. 增加管理端登录鉴权和角色权限。
4. 接入 ParaTTS、Whisper/faster-whisper 或 2D 数字人 SDK，增强数字人表现力。
5. 准备 PPT 和 7 分钟演示视频。
