## 一键打包

在项目根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/package_delivery.ps1
```

脚本会在 `delivery/` 下生成 `scenic-guide-delivery-时间戳.zip`，并默认排除 `.env`、`node_modules`、`dist`、`tmp`、运行数据库和缓存。

可选参数：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/package_delivery.ps1 -IncludeDist
powershell -ExecutionPolicy Bypass -File scripts/package_delivery.ps1 -IncludeDemoDatabase
```

`-IncludeDist` 仅在需要把已构建前端一并交付时使用。`-IncludeDemoDatabase` 仅在明确要求“演示带库”时使用，常规提交和源码交付不建议使用。

## 数据库策略

默认采用“启动重建”模式：交付包不包含 `backend/data/scenic_guide.db`。老师或评审拿到源码后，复制 `.env.example` 为 `.env`，安装依赖并启动后端，系统会自动根据内置种子数据和 `示范景区公开资料包/` 重建 SQLite 运行库。

如需“演示带库”模式，应先确认数据库内没有本机密钥或个人数据，再使用 `-IncludeDemoDatabase` 单独生成演示包，并在提交说明中标记该包包含运行数据库。
